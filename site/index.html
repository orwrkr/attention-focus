Attention Focus
Guide Source

Know where your time went.

A small Windows tray application that records the time you choose to spend on projects and tasks. Pick an activity, start the timer, and see where your time went.

Download for Windows View the source

Windows x64 · one EXE, no installer · MIT License

It stays on your computer

There are no accounts, network access or telemetry, and it does not watch your screen or keyboard or score your productivity. Time is what you declare, not what a program guesses. History and settings live in your Windows profile, in SQLite and text files.

What it does

  • Tray first. Double-click the tray icon to start or stop, click to open the window, and hover to see the current session and today's time.
  • One-click switching. Changing project or task saves the old interval and starts the next at the same moment, so nothing is lost or counted twice.
  • Handles interruptions. Locking Windows, sleep and shutdown stop the timer without resuming on their own.
  • Reports and charts. Totals by project, task and day for any period and time zone, a timeline, columns per day and your weekly rhythm. Export to CSV or Markdown.
  • Corrections. Edit or delete an interval, or add one you missed. Intervals never overlap, and every change is kept in the history file.
  • Thirteen languages and light and dark themes, following Windows or your choice.

Install

  1. Download attention-focus.exe from the latest release.
  2. Put it in a folder you will keep, and run it. That one file is the whole application.

The EXE is not code-signed yet, so Windows SmartScreen may warn about it the first time. Choose More info, then Run anyway, if you trust the download. Each release lists the SHA-256 hash of every file in release.json.
